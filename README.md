# Hi, I'm David Lozano

### Telematics Engineering Student | Systems Programming | Networking & Distributed Systems

I'm a Data Systems Technologist currently pursuing a degree in Telematics Engineering at Universidad Distrital Francisco José de Caldas. I'm interested in understanding how software works under the hood and building reliable, efficient systems that solve real-world problems.

My main interests are **systems programming with C++, computer networking, distributed systems, and software architecture**. I also explore software quality assurance, full-stack development, and the infrastructure behind modern computing systems.

## What I'm Interested In

- **Systems Programming:** C++, data structures, memory management, and low-level software design.
- **Networking & Distributed Systems:** Communication protocols, state synchronization, fault tolerance, and system reliability.
- **Software Architecture:** Modular, maintainable, and scalable systems.
- **Software Quality Assurance:** Test design, exploratory testing, defect reporting, and systematic debugging.
- **Knowledge Management & Local-First Software:** Building tools that organize information and support personal productivity.

## Projects & Research

### Remembo
An academic knowledge management system developed as my degree thesis. It focuses on transforming study notes into flashcards to support active recall and learning.

**Technologies:** Next.js, TypeScript, React, Prisma, PostgreSQL, Neon, and AI integrations.

### Noëka
A personal project exploring a modular, local-first assistant architecture. Its design combines independent subsystems, inter-service communication, message brokering, and graph-based knowledge management.

**Technologies & concepts:** C++, gRPC, RabbitMQ, Neo4j, and modular systems architecture.

### Networking & Synchronization
Exploring multiplayer state synchronization and distributed systems, with an interest in evaluating how different synchronization strategies behave under varying network conditions.

**Areas of interest:** Latency, bandwidth usage, synchronization accuracy, performance, and adaptive strategies.
